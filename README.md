# A.L.L.I.S

Proyecto Android para Allis pre-Alpha v0.4, una IA estilo JARVIS/FRIDAY con escucha activa 24/7, memoria jerárquica e interfaz reactiva tipo esfera.

## Estructura
- `app/` código Android (Compose + servicios).
- `docs/ALLIS_PROMPT.md` prompt de continuidad y visión del sistema.
- `docs/ALLIS_MASTER_PROMPT.md` prompt maestro definitivo con reglas cognitivas completas.

## Nota
Este repositorio establece la base del sistema. Los módulos avanzados se añadirán por iteraciones sin eliminar funciones existentes.
